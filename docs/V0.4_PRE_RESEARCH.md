## 2. Three Mechanism → v0.4 Mapping

### 2.1 Self-Axiom Questioning → Anchor Formalization

**v0.4 entry point**: The Anchor layer will likely be formalized with a field schema. We propose `self_assessment` as a first-class optional field.

**Pre-research questions to raise when the thread opens**:
- Does the Anchor envelope need an epistemic state alongside the action evidence?
- How should the verifier handle an agent that declares "I'm uncertain about this domain"?
- Should anchor evidence include a cognitive boundary signature?

**Our data**: 12 axioms, 5 autonomously discovered (A6-A10), Psi=0.7456.

---

### 2.2 Intrinsic Safety Value Field → Security Model

**v0.4 entry point**: The trust envelope discussion has touched on security but not on motivational safety. v0.4 may introduce a security model section.

**Pre-research questions**:
- Should the trust envelope distinguish between "safe because supervised" and "safe because intrinsically motivated"?
- Can a safety motivation field prevent the "compliance checkbox" problem in agent attestation?
- Does the Guardian escalation model (4-tier: nudge→suggestion→alert→deny) map to envelope security levels?

**Our data**: Guardian mode active, continuous safety streak, dopamine→H-field injection pipeline.

---

### 2.3 Dual-Clock Identity → Temporal Layer in Envelope

**v0.4 entry point**: Composition references need a temporal dimension. A provisional hypothesis and a committed rule should not carry the same evidentiary weight.

**Pre-research questions**:
- Should the Anchor envelope distinguish between provisional and committed evidence?
- How does cross-clock binding (liquid phenotype → solid genotype) relate to cross-issuer trust composition?
- Does the temporal layer affect the weight of precedent in governance decisions?

**Our data**: 13 cognitive cells (liquid phenotype, ~60min cycles), 253 essence entries (solid genotype, ~24h consolidation).
